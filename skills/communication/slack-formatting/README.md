# Slack Formatting

> Format output for Slack delivery — mrkdwn text and Block Kit JSON blocks for rich messages.

## What It Does

Defines two delivery modes for Slack: mrkdwn text for simple messages via `send_message`, and Block Kit JSON for rich layouts with tables, alerts, cards, and buttons. Includes the critical rule that pipe tables in mrkdwn render as garbage — always use Block Kit `markdown` or `table` blocks for tabular data. Gateway auto-detects Block Kit JSON pass-through.

## Quick Example

```
Input:  "Send project digest to Slack"

Output (Block Kit JSON):
{"text": "Project Digest", "blocks": [
  {"type": "header", "text": {"type": "plain_text", "text": "📊 Project Digest – Sep 4"}},
  {"type": "section", "text": {"type": "mrkdwn", "text": "*28 active* | 🟢 3 on track | 🔴 16 overdue"}},
  {"type": "divider"},
  {"type": "markdown", "text": "| PRJ | Project | Health |\n|-----|---------|--------|\n| 001 | Alam Flora | 🟢 |"},
  {"type": "context", "elements": [{"type": "mrkdwn", "text": "Generated by Project Agent"}]}
]}
```

## When to Use / When NOT To

**Use when:**
- Delivering any content to Slack channels
- Sending tables, alerts, or structured data to Slack
- Creating threaded multi-message reports for long content

**Don't use for:**
- Lark delivery → use lark-formatting skill
- WhatsApp delivery → use whatsapp-formatting skill
- Raw pipe tables in mrkdwn text (they render as literal pipes)

## Prerequisites

- [ ] Slack bot token or gateway configured for Slack delivery
- [ ] Understanding of Block Kit block types (header, section, table, alert, context, actions)
- [ ] Max 50 blocks per message, 3000 chars per mrkdwn text field
