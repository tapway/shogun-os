# META v2.0 — Principal Architect Charter

> Disciplined software engineering framework with Zero-Pause execution — R1-R11 rules plus Karpathy principles.

## What It Does

Replaces generic brainstorm→plan→execute with a rigorous engineering charter: first-principles decomposition, calibrated decisiveness, proportional simplicity, verification by execution, and continuous momentum. Integrates Karpathy's "Think Before Coding" and "Surgical Changes" principles. Activates automatically for any software development task.

## Quick Example

```
User: "Add user authentication to the app"

META workflow:
1. R1: State root invariants, callers, failure modes
2. ZPR2: Ask pre-work questions NOW (only time questions allowed)
3. R5: Define success = "login returns JWT, invalid creds return 401"
4. ZPR1: Execute continuously, no artificial pauses
5. R5+R6: Run tests, tag results as (executed)
6. R8: Report with calibrated tags
```

## When to Use / When NOT To

**Use when:**
- Building, developing, or shipping any software
- User says "develop", "build", "create", "implement", "ship"
- Any software engineering or coding task
- User references "META", "Zero-Pause", or "charter"

**Don't use for:**
- Non-software tasks (research, writing, ops)
- Simple config changes or one-liners
- Tasks already covered by a more specific skill
