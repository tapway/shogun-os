# Furniture Rubric

## Standard Plantation Staff Quarter Furniture

| Item | Expected per occupant |
|------|----------------------|
| Bed (single) | 1 |
| Mattress | 1 |
| Study table | 1 (shared OK) |
| Chair | 1 |
| Locker/wardrobe | 1 (shared OK) |
| Ceiling fan | 1 per room |
| Shelf | 1 (optional) |

## Condition Ratings

| Rating | Meaning |
|--------|---------|
| Good | Functional, no damage, clean |
| Fair | Functional but worn, minor damage |
| Poor | Non-functional, broken, or missing parts |

## Counting Rules

- Count only what is **visible** in the photo
- If a bed is partially obscured, still count it if identifiable
- If two beds are stacked (bunk bed), count as 1 bunk bed with quantity 2
- "At least N" when uncertain due to camera angle
- Do not count items that belong to the building structure (doors, windows, built-in shelves)
