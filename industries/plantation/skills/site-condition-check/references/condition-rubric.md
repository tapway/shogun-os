# Site Condition Rubric

## Structural Elements

### Walls
| Condition | Visual Indicators |
|-----------|-------------------|
| Intact | No visible cracks, paint intact |
| Cracks | Hairline or visible cracks in plaster/wall |
| Water damage | Discoloration, peeling paint, mold (water-related) |
| Structural issues | Large cracks, bowing, missing sections |

**Note:** Wall stains/dirt = cleanliness issue (`cleanliness-check`). Wall cracks = structural issue (here).

### Ceiling
| Condition | Visual Indicators |
|-----------|-------------------|
| Intact | Smooth, no damage, fan working if present |
| Leaks | Water stains, dripping, mold on ceiling |
| Missing panels | Holes, incomplete ceiling sections |

### Windows
| Condition | Visual Indicators |
|-----------|-------------------|
| Present & functional | Glass intact, frame sound, can open/close |
| Broken | Cracked/broken glass, damaged frame |
| Missing | No window where one should be |
| Not visible | Not in frame |

### Lighting
| Condition | Visual Indicators |
|-----------|-------------------|
| Functional | Light fixture present, bulb working, switch visible |
| Partial | Fixture present, bulb missing/broken |
| None | No light fixture |

### Ventilation
| Condition | Visual Indicators |
|-----------|-------------------|
| Adequate | Windows present + fan/vent, air circulation |
| Poor | No windows, sealed room, no fan |

## Habitability Scale

| Rating | Criteria |
|--------|---------|
| Good | All structures intact, no hazards, good ventilation |
| Acceptable | Minor wear, no major hazards, ventilation adequate |
| Needs Maintenance | Cracks, leaks, broken windows, or minor safety issues |
| Uninhabitable | Structural damage, major safety hazards, no ventilation |

## Safety Hazards to Scan

- Exposed electrical wiring
- Broken glass
- Structural damage (large cracks, bowing walls)
- Fire hazards (no fire extinguisher, flammable materials near cooking area)
- Missing safety grills on windows (ground floor)
- No emergency exit

If none visible: state "None visible" — do not leave the field empty.

## Priority Action Rules

- List at most 3 structural/safety actions
- Order by severity (safety first, then structural, then ventilation)
- Do not include cleanliness actions (that's `cleanliness-check`'s domain)
